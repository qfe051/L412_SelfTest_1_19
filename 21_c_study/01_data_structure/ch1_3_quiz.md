## Q31. 코드 해석 — 순서리스트 삽입

```c
bool insert(List *L, int pos, int value) {
    if (L->length >= MAX_SIZE) return false;
    if (pos < 0 || pos > L->length) return false;

    for (int i = L->length; i > pos; i--) {
        L->data[i] = L->data[i - 1];
    }

    L->data[pos] = value;
    L->length++;
    return true;
}
```

**문제**

1. 이 함수의 목적은?
2. 왜 `for`문이 뒤에서 앞으로 도는가?
3. `pos == L->length` 이면 어떤 의미인가?
4. 시간복잡도는?
